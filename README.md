# LLM Safety Evaluation

This project explores how to evaluate the reliability and safety of an
LLM-based assistant used for business decision support.

The objective is to develop a reproducible evaluation covering failure
modes such as:

- unsupported claims;
- hallucinated facts;
- inappropriate confidence;
- failure to recognize missing information;
- inconsistent responses;
- unsafe handling of untrusted instructions.

The project will use synthetic business scenarios and will not contain
proprietary or confidential information.

## Planned deliverables

- Synthetic evaluation dataset
- Python evaluation notebook
- Evaluation metrics
- Failure taxonomy
- Results summary
- Recommended mitigations
